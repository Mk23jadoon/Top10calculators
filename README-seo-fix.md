# SEO Meta Tag Fix - Implementation Guide

## 📁 Files Created:
1. `meta-generator.php` - Generates SEO meta tags for all pages
2. `seo-fix.php` - Batch updates all calculator pages
3. `seo-backups/` - Directory for backups

## 🚀 Quick Start:

### Option 1: Web Interface
1. Upload files to your server
2. Visit: `https://yoursite.com/seo-fix.php?action=fix_all`
3. All pages will be updated automatically

### Option 2: Command Line (SSH)
```bash
# Fix all pages
php seo-fix.php

# Fix single page
php seo-fix.php geometrycalc
